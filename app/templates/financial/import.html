Import Instructions

Upload a CSV or Excel file to bulk-import transactions. The file must contain the following columns:

  • type — income or expense
  • amount — numeric value (e.g. 150.00)
  • payee — name of the payee
  • category — transaction category (optional)
  • payment_method — cash, card, transfer, or check (optional)
  • description — free-text description (optional)
  • location_id — numeric ID of the location
  • date — transaction date in YYYY-MM-DD format (optional)
Tip: The first row of your file should be the column headers. Duplicate detection is performed automatically based on amount, payee, date, and location.
